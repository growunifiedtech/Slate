## 🌟 Key Architecture & Features

1. **Continuous 3D Factory Journey (Scroll = Camera Movement):**
   - **Stage 01:** Exterior Entrance & Industrial Portal
   - **Stage 02:** Raw Material & High-Density Textile Roll Inventory
   - **Stage 03:** Automated CAD & Laser Cutting Floor
   - **Stage 04:** High-Tensile Stitching Lines & 50,000 Capacity Monument
   - **Stage 05:** 4-Tier Quality Control (Fabric • Stitching • Finishing • Final Check)
   - **Stage 06:** High-Pressure Steam Finishing & Trim Stations
   - **Stage 07:** Automated Conveyor Packaging & Custom Brand Cartons
   - **Stage 08:** Export Freight Dispatch Logistics Hub
   - **Stage 09:** Architectural Threshold to Luxury Showroom

2. **Luxury Curated Product Showroom:**
   - **Winters:** Heavyweight Hoodies, Varsity Jackets, Puffer Jackets, Leather Jackets, Fleece, Omniheat Tracksuits
   - **Summers:** Oversized Drop-Shoulder Tees (240+ GSM), Round Necks, Pique Cotton Polos
   - **Top & Bottom Wear:** Balloon Fit Tracks, Heavy Fleece Joggers, Technical Softshells
   - **Standard Specifications:** Pricing `₹599 – ₹1,999`, MOQ per product, 5–6 standard sizes (S to 3XL).

3. **Interactive 3D Private-Label Trim Simulator:**
   - Real-time 3D simulation of luxury **Woven Damask Neck Labels**, **Embossed Leather Patches**, and **Soft-Touch Hangtags**.
   - Dynamic live typography reflecting custom client brand names on the 3D woven weave with 360° orbit inspection.

4. **Authentic "Inside Slate" Factory Gallery:**
   - Real high-resolution photography of the New Delhi production facility with full-screen lightbox.

5. **Audio & Ambience:**
   - Web Audio API procedural industrial drone, rhythmic mechanical tempo, and showroom harmonics with mute/unmute control.

6. **Monochromatic Luxury Aesthetic:**
   - Strictly engineered in pure monochromatic tones: Jet Black (`#050507`), Slate Gray (`#171c26`), Carbon (`#090b10`), Industrial Chrome/Silver (`#cbd5e0`), and Crisp White (`#f8fafc`).

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, TypeScript)
- **3D Graphics:** [Three.js](https://threejs.org/) & [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) & [@react-three/drei](https://github.com/pmndrs/drei)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Audio Engine:** Web Audio API Procedural Synthesizer

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Start production server
npm start
```
